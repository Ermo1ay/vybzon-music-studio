VYBZON MUSIC STUDIO — исходный проект Android

В проекте:
- Фирменный шаблон с изображением VYBZON MUSIC.
- 8 встроенных музыкальных дизайнов.
- Вертикальная сцена 9:16 для TikTok.
- Размеры экспорта в HTML-прототипе: 720p, 1080p и 4K.
- Предпросмотр на холсте уменьшенного размера и ограничение частоты кадров для снижения нагрузки.

Важно:
Это исходный проект, а не готовый APK. HTML-прототип экспортирует WebM, а не MP4. Для настоящего MP4-экспорта нужна отдельная нативная реализация кодирования. Экспорт 4K может быть тяжёлым даже в приложении; сначала проверяйте 1080p.

Сборка APK с телефона через GitHub Actions:
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него содержимое папки SoundwaveStudio, сохранив структуру папок, включая .github/workflows/build-apk.yml.
3. Откройте вкладку Actions в репозитории.
4. Выберите "Build VYBZON MUSIC APK".
5. Нажмите "Run workflow" (или дождитесь сборки после загрузки файлов).
6. Откройте завершённый запуск сборки и скачайте артефакт VYBZON-MUSIC-APK.
7. Распакуйте скачанный архив на Android и нажмите на APK для установки. Если Android спросит, разрешите установку из этого источника.

Если сборка завершится ошибкой, откройте её лог и пришлите скриншот ошибки. APK пока не собран и не проверен на устройстве.
